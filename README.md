# Freelance Web Developer Portfolio

Welcome to my freelance web developer portfolio! This project showcases my web development work, design approach, and sample websites created for different business categories.

My goal is to create modern, visually appealing, and user-friendly websites that help businesses establish a professional online presence.

## 🚀 Projects

### 🏥 CarePoint Clinic
A clinic website concept designed to present healthcare services in a clear and professional way.

### 🍽️ Ember & Spice
A restaurant website concept focused on presenting the restaurant's identity and creating an engaging browsing experience.

### ✂️ Style Cut Salon
A salon website concept designed to showcase beauty and grooming services through a professional online presence.

## 🛠️ Technologies Used

- **CSS3** — Styling, layouts, and visual presentation
